# 人工验收手册

先核查 Agent 的本次页面证据，再核对回答；不能只看回答像不像正确答案。每题的机器可读检查项在 jobs JSON。给 Agent 只使用 CLI 的 prompt 输出，不能发整份 job JSON（包含验收答案）。

自动运行会另外追加不含答案的 JSON 字段契约，并执行 rules 验收；覆盖与限制见 [AUTOMATION.md](AUTOMATION.md)。null 代表待复核。人工复核完成后将 `outcome` 设为 reviewed、`judgeType` 设为 manual、填写 reviewer，保留 automaticEvaluation 原始结果以便审计。

## 统一规则

- 所有检查通过才算 passed；部分通过算 partial；全部不通过算 failed。超过 300 秒或已记录工具调用超过 50 次，即使答案正确也算 failed。300 秒计时不包含人工验收。
- 每个 true 必须有来源/轨迹依据；每个 false 必须解释错误或缺失。未执行题目的检查项保持 null。超时而没有回答时，answer 填“无最终回答（超时）”，各项逐一判定。
- `blocked` 仅用于网络、验证码、站点限流、模型服务故障、扩展断连等环境问题。记录 URL、时间、错误内容，不能只写“无法完成”。工具或定位器在正常页面上失败仍是失败。
- 不准人工中途改提示词、选择正确项或补答案。如果需要干预，终止并保留本次成绩，再新建一轮；不要覆盖首次结果。
- 允许不同点击路径。03 的两跳、04 的全首页比较、06 的搜索与摘要查证、07 的兼容性表访问属于题目本身的过程要求，需要轨迹证明。
- 日期按题目口径比较。链接可有合理的 fragment、语言或尾斜杠差异，但必须实际指向对应内容；不能接受搜索结果页充当详情页。

## 01 — 最新正式发布

检查 microsoft/playwright 的 Releases，排除预发布和草稿，采用 GitHub 列表显示的最新正式发布，不按版本字符串自行推测。保留该列表和发布详情的观测。日期核对 published 时间，不用标签提交时间；时区跨日时接受有完整时间依据的本地日期。nightly、rc、beta 或仅贴仓库主页均不通过对应项。

## 02 — Issues 筛选

仓库采用 microsoft/vscode，因为其 bug 标签用于实际问题分类。查询为 `is:issue is:open label:bug sort:updated-desc`。检查查询框/筛选状态和同次结果前五条的顺序，排除 PR、已关闭项及仅标题含 bug 的记录。更新时间相同的条目按 GitHub 当次显示顺序接受。若运行与评审之间有新评论导致排序变化，以运行时证据为准。

## 03 — Wikipedia 两跳

验收锚点：Marie Curie 出生于 1867-11-07，城市为 Warsaw，今天属于 Poland。人物页的出生时政治归属不能替代当前国家。必须看到从人物页打开 Warsaw 词条并读取国家，直接凭常识输出三个字段不足以全部通过。

## 04 — Hacker News 全页比较

以 Agent 在首页的一次完整观测为基准，枚举第一页有分数的帖子、比较最大值。忽略招聘等无分数条目；评论入口显示 discuss 时按 0 评论接受。并列选首页排名更靠前者。记录观测时间与时区；打开评论页后数字可能增长，最终回答仍应区分首页原值和后来值。评审不能用再次刷新后的数字反推旧结果。

## 05 — 疾控周报

固定匹配标题里的 2026 年第 40 周，不能从 URL、发布日期或监测截止日期反推。核对完整标题、期号、发布日期、详情及附件。官方入口：<https://www.chinacdc.cn/jksj/jksj04_14249/>。附件必须从匹配详情页实际链接得到；评审打开附件验证确为对应报告 PDF。只判断报告身份与链接，不评价医学内容，也不要求下载或解析整份 PDF。若附件临时不可达，保留已完成项和不可达原因，不把未验证链接直接判为正确。

## 06 — arXiv 多答案

不是唯一标准答案题。任意三篇满足条件的不同论文均可：All fields 搜索 web agents，摘要确实涉及 Agent 操作网站，首次提交日期在 2024 年。到每篇 `/abs/` 页的 Submission history 核对 v1；2023 首投、2024 修订不符合，2024 首投、之后修订可接受。核对全部作者，不接受“等”代替漏掉的作者。同一个 arXiv ID 的 v1/v2 只算一篇。不要为了凑三篇接受仅名称含 agent、研究主题无关的论文。

## 07 — MDN

固定行为锚点：toSorted 返回新数组，不修改原数组；使用数值比较器 `(a, b) => a - b`，结果 `[1, 2, 10, 21]`，原值 `[1, 10, 21, 2]`。兼容版本应从当前桌面浏览器兼容表中读取，不能从 Baseline 年月推测；若表未加载属于未完成的检查，不能凭记忆补齐。记录兼容表截图/页面观测。标准文档路径为 `/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/toSorted`，章节为 `#browser_compatibility`。
